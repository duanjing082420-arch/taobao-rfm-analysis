## 一、数据清洗（剔除 0.48%）

清洗规则每条都有业务理由，而非机械去重：

| 规则 | 理由 |
|---|---|
| 完全重复行去重 | 埋点重发/日志重复落盘会虚增 PV |
| 剔除时间窗口外记录 | 时间戳跑到 2016/2018 年的属于系统错误 |
| 剔除 user_id / item_id 为空 | 无法归因的行为没有分析价值 |
| 剔除金额 ≤ 0 的订单 | 退款单、测试单会虚增/扰动 GMV |

**关键认知**：剔除比例 0.48% 本身是质量信号——剔太多（如 30%）说明规则误杀，剔太少说明脏数据没被识别。

## 二、核心指标：同一件事，两个差 31 倍的数

| 口径 | 转化率 | 回答的问题 |
|---|---|---|
| 用户级（人数） | 69.31% | 拉来的人质量如何？ |
| 行为级（次数） | 2.22% | 详情页打动人的效率如何？ |

两个都对，分母不同。汇报时必须说明口径，否则无法对齐。

其他：复购率 55.41%，人均下单 2.86 次，买家人均 GMV 545 元。

## 三、漏斗分析：钱丢在哪

结构上有一个容易画错的点：**收藏与加购是并列关系，不是串联**（加购人数 18,794 > 收藏人数 16,168，很多人只加购不收藏）。正确漏斗：

```
浏览 20,000 人 → 深度互动(收藏/加购) 19,641 人 (98.2%) → 下单 13,862 人 (69.3%)
```

**最大价值发现——弃购人群**：
- 5,321 人加购后未付款，弃购率 28.31%
- 按客单价估算，对应 **101.5 万 GMV 缺口**（总 GMV 的 13.4%）
- 这批人是全站意向最高的用户，召回成本远低于拉新

**催付时机**（由加购→下单转化周期分布决定）：
| 间隔 | 占比 |
|---|---|
| 当天 | 18.58% |
| 1 天后 | 13.85% |
| 2 天后 | 10.38% |
| 3 天及以上 | 24.56% |
| 未形成闭环 | 32.63% |

在最终转化的人里只有不到 1/5 是当天买的 → 催付提醒应**分三次触达（当天 / 第 1 天 / 第 3 天）**，只发一次会漏掉八成。

另排查出 **20 个高浏览零转化商品**（170+ 人浏览、有加购、0 下单），疑似详情页、定价或库存问题。

## 四、RFM 分层：41.5% 的人贡献 92% 的 GMV

建模前先探分布（R/F/M 都是长尾分布，不能用平均值一刀切）。F 与 M 解耦验证通过：高频用户客单价 154 元（买日用品），低频用户 234 元（买大件），符合真实电商规律。

| 分层 | 人数 | 占比 | 平均客单价 | 特征 |
|---|---|---|---|---|
| 重要价值客户 | 3,527 | 25.4% | 176.86 | 最近买过 + 高频 + 高额 |
| 重要发展客户 | 2,949 | 21.3% | 339.39 | 新客但金额高 |
| 重要保持客户 | 252 | 1.8% | 221.79 | 以前高频，最近沉默 |
| **重要挽留客户** | **1,585** | 11.4% | **384.29（全站最高）** | 买过大件后沉默，**最该召回的人群** |
| 一般发展/价值/保持 | 3,335 | 24.1% | — | 提频潜力人群 |
| 流失客户 | 2,214 | 16.0% | 89.53 | 低价值，低优先级 |

**方法论要点——为什么不用 NTILE 等频分箱**：F=1（只买过一次）的 6,181 人会被 NTILE 硬拆成 3 种不同分数，两个行为完全相同的人被分成不同层级。改用业务规则分箱后，"重要价值客户"从 36.9% 降到 25.4%，"重要挽留客户"从 6.3% 升到 11.4%——**分层结论对阈值敏感，汇报时必须交代**。

## 五、运营建议（含 GMV 测算）

| 动作包 | 人群 | 动作 | 预期增量 GMV |
|---|---|---|---|
| **A 高价值维护**（25.4% 人，57.1% GMV） | 重要价值客户 3,527 人 | 会员权益、新品优先购、防流失监控（R>2 天预警） | 守住 431.6 万基本盘 |
| **B 高价值召回**（13.3% 人，13.5% GMV） | 重要挽留 1,585 + 重要保持 252 | 大额定向券 + 品类 169/29 定向推送 | 10% 回流 1 单 ≈ **+7.1 万** |
| **C 弃购催付**（全站） | 弃购 5,321 人 | 三段式触达（当天/1 天/3 天） | 召回 20% ≈ **+20.3 万** |
| **D 提频培养**（45.1% 人，26.4% GMV） | 一般发展客户等 | 首购复购券、品类 169 满减 | 转化为重要发展客户 |
| 低优先级观察 | 流失客户 2,214 人 | 不主动投入，仅靠大促自然回流 | 控制成本 |

**投放时机**：GMV 与转化率双高峰在 **20-23 点**（22 点 GMV 76.3 万、转化率 2.78%，是凌晨 3-5 点的 1.8 倍），推送与广告预算向该时段倾斜。
**主推品类**：169 / 29 / 396 三类在各价值层均为 TOP3，头部集中，资源不必分散。

## 六、局限与改进方向

1. **数据为仿真生成**（分布对齐天池真实数据），用于完整跑通方法论；真实项目中需替换数据源后重跑同一套 SQL。
2. 仿真数据用户活跃度高于真实全站（人均 99.8 次行为），"跳失率"类指标参考价值有限；RFM 与漏斗的方向性结论可靠。
3. 弃购缺口为估算口径（弃购人数 × 客单价），实际召回率受触达渠道影响。
4. 后续可引入：MySQL 迁移（脚本已兼容）、用户生命周期价值（LTV）建模、A/B 实验验证运营策略。
